# Туристическое агентство по Таджикистану — лабораторная работа №11

Продолжение лабораторной №10: HTML5, CSS, Bootstrap 5.3, JavaScript ES-модули, временное API на PHP. Все названия маршрутов и цены используются в учебных целях.

## Состав проекта

- `public/static/layout.html` — главная страница.
- `public/static/tours.html` — каталог с живым поиском, фильтром и кнопками удаления.
- `public/static/tour.html` — подробная карточка тура, кнопка бронирования, модальное подтверждение.
- `public/static/booking-form.html` — форма заявки с JS-валидацией и правилом сравнения дат.
- `public/static/tour-form.html` — добавление тура со встроенной HTML5-валидацией.
- `public/assets/js/app.js` — debounce, fetch, AbortController, безопасный DOM, форма и модалка.
- `public/assets/css/app.css` — дизайн, сохранённый с лабораторной №10.
- `public/api/tours/index.php` — 7 учебных записей в JSON с поиском без учёта регистра.
- `docs/11-screens/` — поместите сюда скриншоты для отчёта (пока пусто).

## Запуск (важно)

Из корня распакованного проекта:

```bash
php -S localhost:8000 -t public
```

Откройте http://localhost:8000/static/layout.html

**Нельзя открывать файл через `file://`:** модуль может быть заблокирован браузером, а PHP-файл не выполнится.

Проверьте API: http://localhost:8000/api/tours?q=оз — будут найдены «Семь озёр» и «Озеро Искандеркуль».

## Демо-ограничения

- Серверная обработка `/bookings/create`, `/tours/create` и `/tours/{id}/delete` пока не реализована. Правильно заполненная форма/подтверждение ведут к 404 — как в лабораторном образце, это ожидаемо. Реальная запись в БД, загрузка файлов и удаление не выполняются.
- В каталоге 7 записей: 6 названий туристических маршрутов и 1 тестовая с HTML-тегом в названии. Она проверяет, что текст безопасно выводится через `textContent`.
- Данные не являются коммерческими предложениями. Для реального сайта необходима повторная проверка полей на сервере, авторизация и защита от CSRF для изменяющих операций.
- Bootstrap и шрифт Inter подгружаются через интернет.

## Тесты вручную

1. Каталог: запрос `оз` после 300 мс покажет два маршрута; запрос «несуществующий маршрут» — сообщение о пустом списке.
2. Форма: пустой `booking-form.html` показывает ошибки; установите дату окончания раньше начала — красное сообщение. Исправьте дату — сообщение исчезнет.
3. Каталог: у тестовой карточки название содержит видимые символы `<b>` и `</b>`, но не становится жирным.
4. Кнопка «Удалить» открывает Bootstrap-модалку; нажатие Escape закрывает её.
5. После остановки сервера поиск сообщает об ошибке соединения.
