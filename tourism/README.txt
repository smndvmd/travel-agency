НАСБ (XAMPP):
1. Папкаи "tourism"-ро ба C:\xampp\htdocs\ гузоред.
2. Apache ва MySQL-ро фаъол кунед.
3. Дар phpMyAdmin → "Import" → файли database.sql (ё Tab SQL-ро пур кунед).
4. Агар парол/корбари MySQL фарқ кунад, config.php-ро тағйир диҳед.
5. Кушоед: http://localhost/tourism/

Талаб: PHP 8.0+, MySQL 8 / MariaDB 10.2+.
