# Учебный веб-проект: туристическое агентство для туров по Таджикистану

Лабораторная работа №10: адаптивная статическая вёрстка HTML5, CSS, Bootstrap 5.3.

## Файлы
- `public/static/layout.html` — главная страница;
- `public/static/tours.html` — каталог с демонстрационной формой;
- `public/static/tour.html` — карточка тура;
- `public/assets/css/app.css` — стили и CSS-переменные;
- `docs/10-screens/` — место для скриншотов тестирования.

## Запуск
Откройте `public/static/layout.html` через VS Code Live Server либо запустите из корня папки проекта:

```bash
php -S localhost:8000 -t public
```

Затем перейдите по адресу `http://localhost:8000/static/layout.html`.
Bootstrap и Google Fonts загружаются из интернета. Для работы без интернета нужны локальные файлы этих библиотек.

Все маршруты, цены и длительности являются учебными примерами, не коммерческим предложением. Фильтрация и бронирование не реализованы в статической лабораторной работе.
